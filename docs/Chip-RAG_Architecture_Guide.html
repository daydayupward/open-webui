RETRIEVAL PIPELINE03 / 07
03 · Grounding & context

Parent-Child：精确匹配 + 丰富证据

为什么不是固定大块？

  • 子块约 300 tokens：更适合向量匹配与精确定位。
  • 父块约 2000 tokens：提供完整规则、表格和上下文。
  • 检索命中子块后注入 parent_text，避免回答只看到短片段。
子块重叠50 tokens
父块重叠500 tokens

EXPERT LOOPS05 / 07
05 · Positioning

相对主流 RAG，Chip-RAG 的差异化

领域适配

PDK、EDA、Metrics 三类专家与元数据过滤共同收窄问题空间。

证据闭环

工程安全

SQL 写操作阻断、脚本危险命令拦截、流式链路可观测。

DIFFERENTIATION06 / 07
06 · Roadmap

下一步：从可用走向可度量

短期 P0

混合检索（BM25 + 向量）；对话摘要 + 窗口；统一引用数据契约；建立回归查询集。

中期 P1

HyDE 查询扩展；缓存层；自动化评估流水线；按任务风险动态选择专家与验证强度。

长期方向

多模态图文理解、知识图谱、工具调用与跨项目知识治理。

建议指标

检索召回率> 95%
幻觉率< 2%
首 token 延迟< 1s
